archi-ai-labs

A Claude Code plugin marketplace. Two plugins today; one command registers the catalog and switches on what you ask for.

Install globally

$ curl -fsSL https://archi-ai-labs.github.io/agent-marketplace/install.sh | bash

Or pick the plugins

$ curl -fsSL https://archi-ai-labs.github.io/agent-marketplace/install.sh | bash -s -- --plugins trim-kit,docs-kit,now-board

With no arguments the installer enables only trim-kit. docs-kit registers hooks, so it is opt-in.

trim-kit trim-kit@archi-ai-labs

Audits a project's Claude Code config and says what to add and what to cut — then applies it. Plain skills only: no hooks, no agents, no MCP.

docs-kit docs-kit@archi-ai-labs

Gives a repo a documentation model with a spine: three layers, one direction of change, deterministic checks, and an HTML read model generated from the markdown.

now-board now-board@archi-ai-labs

Keeps a 30-second board per repo — the live thread and its next action, what waits on your decision, what waits on someone else — so a context switch doesn't cost twenty minutes of re-reading the diff. Vietnamese output.
